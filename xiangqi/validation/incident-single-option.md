# 单候选推理失败：2026-09-22

12:01:27，棋局 `d9093cd55ba245dea094e2f4ff627d99` 在红方走 `e8d8` 后调用 Laya 返回 503。该局面黑方仅有一个合法应手 `d9e9`，服务仍正常运行。

根因是本地 Laya 0.3.4 的 `DecisionModel.forward` 无条件对候选概率执行 `p.topk(2)`。当候选维度只有 1 时，这段代码会抛出 `RuntimeError: selected index k out of range`。原始进程的详细异常未落盘，但在相同安装版本的实际 SDK forward 中已复现此边界错误。

修复位于 [laya_compat.py](../../laya-zh/laya_compat.py)：在模型输入中增加一个被 mask 屏蔽的填充槽，使内部置信度计算拥有两个槽位；业务问题仍只有原来的一个候选，SDK 仍按原始候选数切片输出。模型照常执行推理，没有虚构候选、绕过模型或修改第三方安装包。

回归检查覆盖：未修复 SDK 确实报错；修复后单候选成功且填充不出现在结果中；多候选输出完全不变；重复安装 hook 不产生叠加。

诊断改进：模型接口返回请求 ID、异常类型和原因摘要，完整堆栈保存在 Laya 服务的 `runtime/inference-errors.log`；象棋侧栏显示失败记录的具体原因及原始响应。可用请求 ID 对照模型日志定位后续问题。
