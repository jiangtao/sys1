## 交互性能与边界

默认引擎搜索时限为 0.3 秒、返回 5 个候选。在本机 MPS Laya 的一次 [极速模式验收](../../xiangqi/validation/fast-play-checks.md)中，Headless Chrome 连续推进 7 个真实半回合：首步约 1,387 ms，之后六步响应间隔为 `457、424、513、480、438、483 ms`，均值约 **466 ms/手**。另一次相同残局的两次 API 请求为 `2972.9 ms` 与 `544.7 ms`，其中首次 Laya 阶段约 `2652 ms`；冷启动、设备、搜索预算和局面复杂度都会改变时延。

守门会拦截不满足同深度、无边界且同分条件的原选；模型服务失败时则保留当前回合并返回可重试错误。引擎给出的候选与最终执行不能记作模型独立搜索能力。当前没有 Jev/Kev 的象棋首选一致率、采纳率和延迟，不能完成三模型棋力或性能排名。
